NAACCR XML: Tumor.minorSalivaryTumorLocation

Description

Documents the specific anatomical location for minor salivary gland tumors.

Rationale

Minor salivary glands exist within many different anatomical locations of the head and neck, but the AJCC Salivary Glands Expert Panel has determined minor salivary glands should be staged with the salivary glands system. There are no ICD-O-3 topography codes that can describe the anatomical location of a minor salivary gland. Schema Discriminator 3 will be used to indicate a tumor arose in the minor salivary gland, and this SSDI will document the anatomical location of the tumor.
