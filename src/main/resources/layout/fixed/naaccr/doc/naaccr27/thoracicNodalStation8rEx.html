NAACCR XML: Tumor.thoracicNodalStation8rEx

Description

Capture if the lymph node station was removed and pathologically examined from a lung cancer resection. Station-level detail allows outcomes research to test whether the current “3+1” specification is optimal, and whether results differ by tumor location and “closest-node” anatomic pathways—aligning with the intent of quality standards.

Rationale

Collection will allow for the ability to refine the current standard based on evolving evidence. The new data item, by including the station number, can establish current groupings and will allow for additional research to optimize the standard based on outcomes.
