NAACCR XML: Tumor.her2IhcSummary

Description

HER2 immunohistochemistry (IHC) Summary is the summary score for HER2 testing by IHC. An IHC test identifies the protein expressed by the ERBB2 gene.

Rationale

HER2 IHC Summary is a Registry Data Collection Variable in AJCC. It was introduced as a new data item for cases diagnosed 1/1/2018-2020 and re-introduced for cases diagnosed 1/1/2027 and forward.

Not required by any standard setter for cases diagnosed 2021-2026.
