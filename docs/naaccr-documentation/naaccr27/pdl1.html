NAACCR XML: Tumor.pdl1

Description

The absence or presence of PD-L1 expression determines if the tumor will respond to treatment with a targeted inhibitor (immunotherapy). PD-L1 is done for Non-small cell lung cancers (NSCLC).

Rationale

PD-L1 is recommended by treatment guidelines for lung cancer to determine if the patient may benefit from checkpoint inhibitor drugs (immunotherapy). It is a new data item for cases diagnosed 1/1/2025+.

Note 1: Effective years

  • This SSDI is effective for diagnosis years 2025+
  • For cases diagnosed 2018-2024, this SSDI must be blank

Note 2: Physician statement

  • Physician statement of PD-L1 can be used to code this data item when no other information is available 

Note 3: Types of PD-L1 testing

  • Tumor Percentage Score (TPS)

  • Combined Percentage Score (CPS)

  • CPS score results will take priority if  both TPS and CPS scores are done

    • CPS is much more extensive than TPS, so if TPS is negative, CPS may still be positive. The results from the CPS score would be recorded
    • If TPS is positive, CPS will be positive
