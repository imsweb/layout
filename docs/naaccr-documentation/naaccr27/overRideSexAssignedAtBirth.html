NAACCR XML: Patient.overRideSexAssignedAtBirth

Description

Some computer edits identify errors. Others indicate possible errors that require manual review for resolution. To eliminate the need to review the same cases repeatedly, over-ride flags have been developed to indicate that data in a record (or records) have been reviewed and, while unusual, are correct.

This over-ride is used with the following edits in the NAACCR Metafile of the EDITS software:

  • Sex Assigned at Birth, Primary Site (SEER) N7210
Rationale

If a patient is assigned a code 1 (male) or 9 (unknown) for Sex and Assigned at Birth and a Primary Site of C510-C589 (female genital organs) or a patient assigned 2 (female) or 9 (unknown) with Primary Site of C600-C639 (male genital organs) will trigger an edit. If the codes are confirmed correct, code 1 may be assigned in Over-ride Sex Assigned at Birth will allow the edit to pass. This data item may be used for all diagnosis years.

Instructions for Coding

  • Leave blank if the program does not generate an error message for the edit Sex Assigned at Birth, Primary Site (SEER) N7210.
  • Leave blank and correct any errors for the case if an item is discovered to be incorrect.
