NAACCR XML: Tumor.geoAddrAtDxPostalCode

Description

Holds the geocoded address at diagnosis produced by the NAACCR geocoder, Geocodio. Applies to all cases that have been geocoded--for which the data are available (registries that do batch upload may not have retained the older data; SEER*DMS registries should have historic data for all Geocodio geocoded cases); US ONLY

Rationale

With the move to Geocodio geocoding software for most registries, some of the historic variables used to assess the geocoded data quality are no longer available.  Registries currently do not have a standardized way to accurately assess the quality of newly geocoded data. Prior work by RDU committees has identified that our current geocoding data quality variables are not sufficient to assess data quality in some cases. These data items are needed to correctly assess the quality for each geocoded case.

This variable is not coded directly. This data item is generated during the geocoding process and just needs a storage location within the registry.
