NAACCR XML: Tumor.dateOfCaStatusFollowing1stCrsTx

Description

This data item documents the date of last cancer status of the patient’s disease after completion of first course treatment. This date correlates to the status recorded in Cancer Status Following First Course of TX [1769]. Record in CCYYMMDD form.

Rationale

This information is used for outcomes studies.
